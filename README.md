# Veda Technology – Task 20: Newsletter Signup Modal

## 📌 Project Overview

The Newsletter Signup Modal is a responsive frontend web application developed using HTML, CSS, and JavaScript. It displays a popup newsletter signup form after a short delay and allows users to dismiss the modal.

## 🎯 Objectives

- Create an interactive popup modal.
- Practice JavaScript timers using `setTimeout()`.
- Validate email input before accepting form submission.
- Handle click events and keyboard interactions.
- Build a responsive and user-friendly interface.

## ✨ Features

- Automatic popup after 3 seconds.
- Email input with validation.
- Close button to dismiss the modal.
- Click outside the popup to close it.
- Press Escape to dismiss the modal.
- Success and error messages.
- Responsive design for desktop and mobile.
- Manual button to open the signup modal.

## 🛠️ Technologies Used

- **HTML5** – Page structure and signup form.
- **CSS3** – Styling, layout, transitions, and responsiveness.
- **JavaScript** – Timer, modal controls, form validation, and event handling.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.
4. Wait 3 seconds for the popup to appear.
5. Test the signup form and close functionality.

## 🧪 Testing

- Verify that the modal appears after 3 seconds.
- Open the modal using the Subscribe button.
- Close it using the close button.
- Click the overlay outside the modal.
- Press Escape to close the modal.
- Try an invalid email address.
- Enter a valid email format and check the demo success message.

## ⚠️ Important Note

This is a frontend demonstration project. It validates the email format and displays a confirmation message, but it does not store email addresses or create actual newsletter subscriptions.
