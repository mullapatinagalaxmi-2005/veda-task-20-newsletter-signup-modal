
# Veda Technology – Task 20: Newsletter Signup Modal

## Project Overview
A responsive newsletter signup modal built using HTML, CSS, and JavaScript. The popup appears after a short delay and can be dismissed by clicking the close button, the overlay, or pressing Escape.

## Features
- Automatic popup after 3 seconds
- Email input with browser validation
- Close button and overlay dismissal
- Escape key support
- Responsive design
- Success and error messages
- Manual subscription button

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Open the project folder in Visual Studio Code.
2. Right-click index.html.
3. Select Open with Live Server.

## Testing
- Confirm the modal appears after 3 seconds.
- Close it using the close button.
- Click outside the modal to dismiss it.
- Press Escape to close it.
- Test an invalid email and a valid email format.

## Important Note
This is a frontend demonstration. No email address is saved and no actual newsletter subscription is created.
